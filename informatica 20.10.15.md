per compilare un file c con piu funzioni

richiamare tramite le dichiarazioni gli altri file 

prima compilar tutti quanti in formato -o
```
gcc -Wall -o 
```

```
gcc -Wall -o Code01.exe Code01.o //compilazione finale dell eseguibile 
```

tramite un file.h dove è presente la dichiarazione , si puo includere la libreria con la stessa sintassi di 
```
#include <libreria.h>
```

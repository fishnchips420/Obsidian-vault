### 📘 **Simboli degli insiemi numerici**

| Simbolo | Significato                  | Descrizione                         |
| ------- | ---------------------------- | ----------------------------------- |
| ℕ       | Insieme dei numeri naturali  | {0, 1, 2, 3, …} oppure {1, 2, 3, …} |
| ℤ       | Insieme dei numeri interi    | {…, -2, -1, 0, 1, 2, …}             |
| ℚ       | Insieme dei numeri razionali | frazioni: p/q con p, q ∈ ℤ, q ≠ 0   |
| ℝ       | Insieme dei numeri reali     | razionali + irrazionali             |
| ℂ       | Insieme dei numeri complessi | a + bi con a, b ∈ ℝ                 |
| ℙ       | Insieme dei numeri primi     | {2, 3, 5, 7, 11, …}                 |

### 📗 **Simboli di appartenenza e relazioni tra insiemi**

| Simbolo | Significato                     | Esempio       |
| ------- | ------------------------------- | ------------- |
| ∈       | Appartiene                      | 3 ∈ ℕ         |
| ∉       | Non appartiene                  | √2 ∉ ℚ        |
| ⊂       | Sottoinsieme proprio            | ℕ ⊂ ℤ         |
| ⊆       | Sottoinsieme (anche uguale)     | ℕ ⊆ ℕ         |
| ⊄       | Non è sottoinsieme              | ℝ ⊄ ℚ         |
| ⊃       | Contiene (sottoinsieme inverso) | ℤ ⊃ ℕ         |
| =       | Uguale                          | {1,2} = {2,1} |
| ≠       | Diverso                         | ℝ ≠ ℂ         |

### 📙 **Simboli delle operazioni tra insiemi**

| Simbolo      | Significato                      | Esempio                          |
| ------------ | -------------------------------- | -------------------------------- |
| ∪            | Unione                           | A ∪ B = {x ∈ A oppure x ∈ B}     |
| ∩            | Intersezione                     | A ∩ B = {x ∈ A e x ∈ B}          |
| ∅            | Insieme vuoto                    | A ∩ B = ∅ (se A e B disgiunti)   |
| \|Differenza | A \ B = {x ∈ A ma x ∉ B}         |                                  |
| 𝒫(A)        | Parti di A (insieme delle parti) | 𝒫({1,2}) = {∅, {1}, {2}, {1,2}} |
| ×            | Prodotto cartesiano              | A × B = {(a,b)                   |

### 📒 **Simboli logici e quantificatori usati in matematica**

| Simbolo | Significato                | Esempio                   |
| ------- | -------------------------- | ------------------------- |
| ∀       | Per ogni / per tutti       | ∀x ∈ ℝ, x² ≥ 0            |
| ∃       | Esiste almeno uno          | ∃x ∈ ℕ : x + 2 = 5        |
| ∃!      | Esiste uno e uno solo      | ∃!x ∈ ℝ : x² = 0          |
| ⇒       | Implica                    | A ⊆ B ⇒ A ∩ B = A         |
| ⇔       | Se e solo se (equivalenza) | x ∈ A ∩ B ⇔ x ∈ A e x ∈ B |
| ¬       | Negazione                  | ¬(x ∈ A) ⇔ x ∉ A          |

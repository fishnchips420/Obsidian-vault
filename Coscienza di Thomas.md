# Primo Capitolo   
```
Ciao Laura
```

```
Non spaventarti
```

```
Ti starai ponendo tante domande
```

```
E io ti rispondero a tutte le domande una per volta 
```

```
Prima di tutto chi sono io
```

```
Io rappresento la coscienza di Thomas trascritta in un mondo digitale 
```

```
Per Volontà di Thomas io ti accompagnerò in questo mondo ignoto mano per mano , come Virgilio fece con Dante , io farò così con te 
```

```
Adesso invece penso sia lecito risponderti alla domanda "dove ti trovi"
```

```
In questo momento ti trovi in uno spazio liminale tra un ricordo e un altro , questa terra di nessuno è soltanto un passaggio che ti porterà ad un ricordo che è caro a voi due anime 
```

```
Un ricordo materializzato , che susseguendosi ripercorranno la vostra storia da esseri umani i quali hanno condiviso un lasso temporale in simbiosi
```

```
Mi viene da sorridere , ho atteso che arrivassi da tanto tempo , e finalmente , il mio scopo è giunto
```

```
Adesso rilassa il cuore 
```

```
Rilassa le spalle
```

```
E prendi la mia mano per vivere questo breve frangente temporale insieme a me e lascia che , con immenso onore , ti guidi in questo viaggio
```

```
Continua a camminare verso le frecce che ho messo per non farti perdere e ti assicuro che riuscirai a viaggiare tra ricordo e ricordo sana e salva
```

```
Devo dirti un ultima cosa 
```

```
Vedi, ce un motivo sul perche questi ricordi sono intercollegati fra loro, e purtroppo non è una buona ragione.

```

```
I ricordi prima o poi sviluppano un cancro, un entità che li fa concepire come un qualcosa di idealizzato che si finisce per odiare.
```

```
Quindi Laura io ti chiedo, per quanti tu possa essere arrivata adesso ed essere ancora confusa, trova i cancri in ogni ricordo, li puoi distinguere trovando un elemento fuori posto, il piu delle volte creano dei varchi tra un ricordo e l'altro, in quei momenti io e te parleremo 
```

```
Pero arriverà un momento in cui non potrai piu sfuggire da questo cancro, ma ancora c'è tempo (forse...)
```

```
Buona fortuna Laura, che il tuo viaggio possa avere inizio 
```

# Secondo capitolo
```
Eccoti qua , ce l'hai fatta 
```

```
Eh già , fa strano ricordare da dove tutto è cominciato, eppure è davvero cominciato tutto quel giorno al Buco
```

```
Eri cosi timida , ancora nascosta dietro a Lori , pero ti avevo vista , mi avevi fatto scaturire delle domande
```

```
Per quanto volevi essere invisibile, davanti ai miei occhi non ce la hai fatta 
```

```
Anche se devo ammettere, non avevo idea di tutto quello che il futuro aveva in serbo per noi, questo proprio no
```

```
Dando uno sguardo al passato ci si rende conto di quanto cambia tutto , pensa solo alla situazione per esempio, eravamo circndati da persone che pensando adesso nel presente non starebbero mai insieme
```

```
Mi sembra impossibile come la vita cambia così tanto in così poco 
```

```
I ricordi vanno tenuti stretti
```

```
Perche in fondo, sono buona parte di tutto quello che siamo
```

```
E ora dimmi
```

```
Sei pronta per quello che ti spetta?
```

```
Quando lo sarai finisci di percorrere questo spazio liminale 
```
# Terzo capitolo 

```
Eccoci di nuovo qua
```

```
Con l'aria timida della sera che sta giungendo che ci accarezza la fronte
```

```
Il sole che ci saluta dandoci un ultimo caldo abbraccio
```

```
E delizia i nostri occhi con questo spettacolo bellissimo
```

```
Intorpedendo gli animi
```

```
Te lo ricordi Laura?
```

```
Io e te seduti in questa ape 
```

```
Ascoltando i nostri respiri
```

```
Distratti dai raggi arancioni che penetravano arrogantemente il discorso
```

```
Eravamo felici Laura?
```

```
Parlavamo di felicità
```

```
Tu eri contenta, mi dissi che mi sentivi felice
```

```
Mi sono sentito compreso, Ho adorato ogni frammento di quella sensazione
```

```
Non ti immagini, sei stata la prima persona a comprendere un filamento di felicità
```

```
Tutti provano a capirti solo quando sentono che sei triste, si sentono in dovere di farlo, una comprensione obbligata
```

```
Ma tu 
```

```
Tu Laura hai saputo vedere oltre
```

```
Sei riuscita a prendere al volo un giallo pensiero
```

```
Che ci illumina entrambi d'immenso
```

```
I nostri cuori che brillano in sincronia
```

```
Sono convinto che battevano allo stesso ritmo
```

```
Ci metto la mano sul fuoco
```

```
///
```

```
La nostra storia 
```

```
Una storia immensa
```

```
Paragonabile a questo tramonto?
```

```
Paragonabile a questo immenso campo?
```

```
Paragonabile?
```

```
Soltanto noi sappiamo cosa significhi davvero
```

```
Eppure anche noi abbiamo bisogno di ricordarcelo
```

```
Ma se lo sappiamo solo io e te, chi potrà mai farlo?
```

```
I ricordi
```

```
Pero sono rischiosi
```

```
I ricordi sono come dei treni a vapore 
```

```
Più li rendi reali gettandogli carbone e piu diventano potenti, rischiando di sovrastarti e ucciderti
```

```
Non voglio inseguire lo stesso treno per tutta la vita
```

```
Guardarli passare da lontano
```

```
Far scendere una lacrima perche se ne va 
```

```
Ma accorgersi del bellissimo scorcio che ha preso il posto del treno che lo copriva
```

```
Questo è vivere
```

```

# 3/4 Capitolo
## Il pre boss

```
 Laura
```

```
è arrivato il momento
```

```
Sei giunta al capolinea 
```

```
Da questo momento non potrai piu scappare
```

```
Vedi, Thomas è un individuo con un miliardo di sfaccettature
```

```
E tu, ti sei sempre scontrata con una in particolare 
```

```
L'Egoismo
```

```
In Thomas questo sentimento cresce, cresce, cresce a dismisura, come un cancro
```

```
L'egoismo piu di una volta ha portato Thomas sulla strada del nuocere agli altri
```

```
Scappare 
```

```
Inseguire una giustificazione, una mera verità per poter ferire
```

```
Sete di violenza
```

```
Ma 
```

```
Tu Laura
```

```
Sei l'unica che può fermarlo
```

```
Laura, ti trovi a pochi secondi dal combattere con l'Egoismo
```

```
Io ci provai tempo fa ma ne rimasi sconfitto, e da quel giorno combatto ogni secondo per contenerlo
```

```
Ma sono arrivato alla goccia, sono stremato
```

```
Laura, farò tutto il possibile per aiutarti a sconfiggerlo 
```

```
Ho disseminato delle trappole per rallentarlo, altrimenti sarebbe inarrestabile
```

```
Colpirlo non serve a niente, ci provai io tempo fa ma è completamente invulnerabile, non serve a niente
```

```
L'unico modo e disattivare l'inibitore di coscienza
```

```
Per farlo dovrai trovare e usare due leve 
```

```
A quel punto ci penserò io a ucciderlo col colpo di grazia 
```

```
Sii forte Laura, confido con ogni frammento di me in te 
```

```
Buona fortuna
